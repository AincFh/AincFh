## How I build / 工作方式

- **Design for people.** 信息清晰、交互顺手，比堆叠视觉效果更重要。
- **Build for reality.** 重视数据可靠性、权限隔离、错误处理和发布过程。
- **Keep improving.** 通过真实项目和持续迭代验证设计，而不是用自评百分比说明能力。
