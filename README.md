<summary>Projects, technology and verification / 项目与工程说明</summary>

### AincFh · AI Native Product Development

围绕真实软件需求组织 AI 辅助研发：确认业务目标和权限边界、设计方案、开发实现、运行测试、修复问题并验证交付。这里展示的产品画面是原创 UI 示意，不是实际产品截图；GitHub README 里的 SVG 可以自动播放动画，但无法在图像中实际操作窗口。

**Selected real projects · 真实项目**

- **[A.T. Field](https://aincfh.dpdns.org)** · 线上内容与社区平台，公开源码 [my-anime-blog](https://github.com/AincFh/my-anime-blog)。React Router SSR、TypeScript、Cloudflare Workers、D1、KV、R2；涉及内容发布、账户、社区和管理功能。
- **[Saint Laurent](https://yslfivem.com)** · 真实运行的 **虚构 FiveM 角色扮演社区**业务平台。包括公开门户、法典检索、授权工作台、KOOK 消息与 AI 助手工作流。Next.js、Node.js、自托管 SQLite；核心源码和内部权限工作流非公开。**所有政府部门称谓均属于游戏世界观，不是现实政府机构。** 不把内部候选版本描述成正式发布。
- **[ATLAS Developer Studio](https://github.com/AincFh/dev-control-center)** · 公开的跨领域软件研发工作空间，含 GitHub 参考研究、项目工作包、浏览器内数据/图像/API 工具和质量验收工作流。外部开源参考与仓库索引不代表自研产品或已发布的软件。
- **[轻记 QingJi](https://github.com/AincFh/QingJi)** · 原生 Android 个人消费记账 **原型**：Kotlin、Jetpack Compose、SQLite；支持本地记录、筛选、统计、预算、CSV 导出。存在 Debug APK 构建记录，但不代表已正式上架、完成真机验收或拥有正式 Release。
- **Windows Tools** · C#、.NET、WinForms、WebView2 桌面客户端及内部工具研发；部分源代码与构建版本不公开。**[Meridian Toolkit](https://github.com/AincFh/meridian-toolkit)** 是另外一个公开的、无需上传文本的浏览器离线开发工具集，提供八项本地实用工具。
- **[AincFh OS](https://github.com/AincFh/AincFh/tree/main/docs)** · 浏览器里的桌面式交互实验。它不是操作系统内核，不能直接访问宿主机文件或进行真实关机操作。README 图像也不是可交互网页。

**Design and status**

本页的半透明玻璃、高光、弱折射和背景层次参考 Apple 的 [Liquid Glass 材质原则](https://developer.apple.com/design/human-interface-guidelines/materials) 与 iOS 26/27 的视觉演进，仅为原创网页展示效果，**并非 Apple 官方界面或系统组件的完整复现**。玻璃材质主要用于窗口和导航控件，内容区域优先保证可读性；深浅色及减少动态效果设置分别适配。真实可交互的浏览器实现以各项目源码和运行说明为准。
