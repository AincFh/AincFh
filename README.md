## How I build · 工作理念

- **Experience matters.** 界面应该清晰、克制、好用，而不只是展示技术效果。
- **Engineering matters.** 关注权限、安全、数据一致性与长期可维护性。
- **Shipping matters.** 以真实使用和持续迭代验证方案，不用虚构的技能百分比代替作品。
